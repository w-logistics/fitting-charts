SAE J518 Code 61 and Code 62 Flange Chart

Four-bolt split flanges for SAE J518. Code 61 is the standard series, ISO 6162-1. Code 62 is the 6,000 psi series, ISO 6162-2. The pad is a flat face with an O-ring in the flange head, held by two clamp halves and four bolts. There is no pipe thread on the port.

Quick rule: Same nominal size, two patterns. A 1/2 in Code 61 head is 1.188 in across, with bolt centers 1.500 in by 0.688 in, and O-ring 2-210. A 1/2 in Code 62 head is 1.250 in across, with bolt centers 1.594 in by 0.717 in, and the same O-ring 2-210. The O-ring does not tell them apart. The head and the bolt rectangle do. If the part in your hand is a threaded fitting, use the identification guide instead of this page.

Code 61 is the standard-pressure series. Parker Catalog 4400 describes it as 3,000 psi to 5,000 psi maximum, depending on size. The SAE 3000 name is the series nickname. It is not the rating on the small sizes. Dash -8, -12, and -16 are 5,000 psi in Parker's clamp table. The same Parker hose-catalog page notes that dash -20, -24, and -32 can be 5,000 psi with 4A, 4F, and 4N fittings and 50H flange halves. The table below uses the standard clamp rating.

The dash is the nominal size in sixteenths of an inch. Dash -8 is 8/16 in, which is 1/2 in. Dash -16 is 1 in. That is the same inch a JIC dash uses for tube OD, and it is not a thread. Parker's port table lists the same maximum bore for both codes: 0.50 in on -8, 0.75 in on -12, 1.00 in on -16, 1.25 in on -20, 1.50 in on -24, and 2.00 in on -32. The bore does not separate Code 61 from Code 62.

Head OD in millimeters, through dash -48, is the inch figure times 25.4, rounded to two decimal places. A remainder of 5 in the next digit is rounded up. Aeroquip prints the same millimeters on 1/2 in through 1-1/4 in (30.18, 38.10, 44.45, 50.80). On 1-1/2 in Aeroquip prints 60.33 mm for a head it lists as 2.38 in. This table uses Parker's plug diameter, 2.380 in, which converts to 60.45 mm. On 2 in Aeroquip prints 71.42 mm and 2.81 in. Parker's plug prints 2.810 in, which converts to 71.37 mm. On 2-1/2 in and 3 in, Hydroscand's SAE J518 diameters are 84.12 mm and 101.60 mm, the same conversions as Parker's 3.312 in and 4.000 in plugs.

Dash -56, -64, and -80 head diameters are Hydroscand's SAE J518 table: 114.30 mm, 127.00 mm, and 152.40 mm. Divided by 25.4 those are 4.500 in, 5.000 in, and 6.000 in. Parker's flange-head plug table stops at 3 in, so those three heads are not copied from Parker.

Inch bolt spacing is the X and Y columns on Parker's captive clamp, short by long, written here as long by short. The millimeter pair is column C by column Y in Parker's ISO 6162 port table. The two roundings are the same pattern. 1.500 in is 38.10 mm, and the port table prints 38.1. Dash -80 is not in the inch clamp table. 152.4 mm / 25.4 is 6.000 in, and 92.1 mm / 25.4 is 3.626 in. Hydroscand prints 152.40 mm by 92.08 mm for that size.

How to tell Code 61 from Code 62

The nominal size can match and the parts still will not assemble. Code 62 uses a larger head and a larger bolt rectangle so the joint can be rated 6,000 psi. Code 61 uses the smaller pattern, and the pressure rating falls as the size goes up.

  1. Measure the head OD across the round disk the clamp sits on. On a 1 in flange, 1.750 in is Code 61 and 1.875 in is Code 62.
  2. Measure both bolt spacings, center to center, the long way and the short way. One direction is not enough. On 3/4 in the long spacing is 1.875 in for Code 61 and 2.000 in for Code 62.
  3. Read the bolt from 1 in upward. A 1 in Code 61 bolt is 3/8-16. A 1 in Code 62 bolt is 7/16-14. On 1/2 in and 3/4 in the thread is the same, so the thread will not separate them.
  4. Look for a V notch on the head. Parker Catalog 4400 says the Code 62 head is V notched for identification. Treat a notch as a hint. A head without a notch still has to be measured.
  5. Do not use the O-ring as the test. Both codes use 2-219 on a 1 in flange.

Brennan describes Caterpillar split flanges as Code 62 dimensions with a flange thickness of 0.560 in. Thickness is not the code. A thicker head on a Code 62 bolt pattern is still the Code 62 pattern. This chart does not list Caterpillar thickness as a separate row.

How to measure a flange

Aeroquip's measuring order is the port hole, then the longest bolt-hole spacing from center to center, or the flanged head diameter. Brennan says the same thing: port hole, then head diameter or the longest bolt center distance. Use a caliper.

  1. Port hole. Measure the open bore. It should be near the nominal size (about 0.50 in on a 1/2 in flange, about 1.00 in on a 1 in flange). Parker prints the same maximum bore for both codes. The hole tells you the nominal size. It does not tell you the code.
  2. Head OD. Measure the round head, not the clamp and not the hose. The clamp is larger than the head. The head is the disk with the O-ring groove in the face.
  3. Bolt pattern. Measure center to center on the long side of the rectangle, then center to center on the short side. Four holes on a rectangle are this chart. Four holes on a square are a different pattern. Parker says there is no industry standard for its square-pattern block flanges.
  4. Bolt thread. Use a pitch gauge. UNC is threads per inch (5/16-18 means 18 threads per inch). Metric pitch is the distance between threads in millimeters (M10 x 1.5 means 1.5 mm from crest to crest). Aeroquip says a port that takes metric bolts is stamped with an M.
  5. Match two dimensions. Head OD and both bolt spacings should land on the same row. If the head says Code 62 and the bolts say Code 61, stop and measure again before you order halves.

Bolt length is not in the tables. Parker prints a length with each clamp, and that length follows the clamp thickness. A 1/2 in Code 61 clamp in the captive-clamp table uses 5/16-18 x 1.25. Use the length for the clamp you are installing. The thread size is what this chart is for.

Common mistakes

  • Reading every Code 61 as 3,000 psi. Dash -8, -12, and -16 are 5,000 psi in Parker's clamp table. Dash -56 and -64 are 500 psi. The nickname is not the cell.
  • Mixing halves across codes. A Code 61 clamp will not sit on a Code 62 head of the same nominal size. The bolt holes will not line up with the port.
  • Ordering the O-ring to pick the code. The number is shared. Order 2-219 for a 1 in flange of either code, then pick the halves from the head and the bolt pattern.
  • Using an ORB ring or an ORFS ring. Dash -16 ORB is 3-916. Dash -16 ORFS is 2-021. Dash -16 flange is 2-219. The ORB chart and the ORFS chart list those other rings.
  • Putting an inch bolt in a metric port. The UNC column and the metric column are two versions of the joint, not two bolts in the same hole. An older Parker port table marks the inch screws "not for new design." Ports already in service still use them. Follow the stamp and the tapped hole.
  • Taking flange-kit pressure as the hose rating. The pressure column is the clamp. A hose end on that flange can be rated lower. Read the hose layline and the hose maker's catalog. The hose chart is the dash of the hose bore, which is a different measurement from this head.
  • Looking up bolt torque on the fitting torque chart. The torque chart is JIC, ORFS, and SAE O-ring boss. It does not list these four bolts. Use the flange maker's torque for the bolt grade and size.

FAQ

How do I tell Code 61 from Code 62?

Code 61 (ISO 6162-1) and Code 62 (ISO 6162-2) use the same nominal size and the same O-ring. They do not share a bolt pattern or a head diameter. On a 1 in flange, Code 61 bolt spacing is 2.062 in by 1.031 in (52.4 mm by 26.2 mm) and the head OD is 1.750 in. Code 62 is 2.250 in by 1.093 in (57.2 mm by 27.8 mm) and the head OD is 1.875 in. Parker Catalog 4400 says the Code 62 head is V notched. Measure the head or the bolt centers. A missing notch is not a measurement.

Do Code 61 and Code 62 use the same O-ring?

Yes, for the same dash. Parker's flange O-ring table lists one number for both codes: 2-210 on dash -8, 2-214 on -12, 2-219 on -16, and the same pattern through 2-253 on dash -80. The ring does not tell the codes apart. It is not an O-ring boss ring. Dash -8 ORB uses 3-908.

Is every Code 61 flange rated 3000 psi?

No. Parker's clamp table rates Code 61 at 5,000 psi on dash -8, -12, and -16, 4,000 psi on -20, 3,000 psi on -24 and -32, 2,500 psi on -40, 2,000 psi on -48, and 500 psi on -56 and -64. Code 62 is the 6,000 psi series through 2 in. The SAE 3000 series name is the nickname for Code 61, not the rating of every size. A hose or adapter on the flange can be rated lower than the clamp.

Which bolt do I use, UNC or metric?

Both exist. Parker's clamp tables use UNC bolts, such as 5/16-18 on a 1/2 in flange. ISO 6162 Type I ports use metric screws, such as M8 x 1.25 on that same 1/2 in size. Aeroquip says a port that needs metric bolts is stamped M. Do not put an inch bolt in a metric tapped hole. On Code 62 dash -20 the catalogs do not all print the same metric size. See the note under the tables.

Can I clamp a Code 62 head with Code 61 halves?

No. The head OD and the bolt rectangle are both larger on Code 62 at the same nominal size. The halves for one code do not match the head and the port of the other. Dash -8 and -12 are the easy ones to mix up, because the bolt thread can be the same and the dimensions are close. Measure both directions of the bolt pattern.

How is a flange dash different from a JIC dash?

The number is the nominal size in sixteenths of an inch, the same way a JIC dash is the tube OD in sixteenths. Dash -16 is 1 in on both charts. The connection is not the same. A -16 JIC is a 1-5/16-12 thread. A -16 flange has no pipe thread on the pad. It seals with O-ring 2-219, clamped by four bolts. The torque chart covers JIC, ORFS, and O-ring boss studs. It does not cover these bolts.

Safety note: A Code 61 head in a Code 62 port, or the reverse, does not seal when the only match is the nominal size. Wrong pattern, wrong bolt, or a cut O-ring is a common cause of hydraulic leaks and failures. Measure the head and both bolt spacings, and compare them with the flange manufacturer for the part you are installing. This page is a reference aid, not a replacement for that data.
