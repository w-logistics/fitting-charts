About FittingCharts

FittingCharts is a free, static reference for identifying inch-series hydraulic fittings. The charts are written for mechanics and shop techs who need a dash size, a thread, and a way to tell similar fittings apart.

The site is not an official publication of SAE, ISO, Parker, Eaton, or Amazon. A chart is a lookup aid. It is not a substitute for the standard, a thread gauge, or the pressure rating the fitting manufacturer publishes for a specific part and material.

Where the numbers come from

  • The JIC chart follows SAE J514 37° flare dash and thread conventions.
  • The ORFS chart uses the Seal-Lok dimension table and ORFS O-ring table in Parker Hannifin Catalog 4300. Parker states that Seal-Lok meets or exceeds SAE J1453 and ISO 8434-3. Sizes -14 and -32 are in that Parker catalog; Parker notes that those two sizes are not included in SAE J1453.

Each chart page names the sources used for its table. If a figure is not in those sources, it is not on the chart.

Analytics

Pages load a GoatCounter count script (fittingcharts.goatcounter.com). GoatCounter is a cookieless counter, so this site does not show a cookie banner and does not set an analytics cookie. It is the only external script the pages load.

Site files

The site is plain HTML and CSS. Source is in the fitting-charts repository.

Safety note: Wrong fitting type or size is a common cause of hydraulic leaks and failures. When in doubt, take measurements and compare to manufacturer data or a known good sample. These pages are a reference aid, not a replacement for proper identification tools and specs.
